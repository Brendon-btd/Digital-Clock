# Digital-Clock
A real-time digital clock built with JavaScript, HTML, and CSS that displays the current date and time in an elegant format. The clock automatically updates every second, showing the day of the week, full date, and time in 12-hour AM/PM format. It features a modern glassmorphism design with a gradient background and starts running immediately when the page loads. The project uses DOM manipulation and JavaScript's Date object to fetch and format time data, with custom padding methods to ensure consistent two-digit display for hours, minutes, and seconds.
